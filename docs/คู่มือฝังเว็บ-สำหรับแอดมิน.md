# คู่มือนำเครื่องมือ "ประเมินความเสี่ยงหัวใจ (Thai CV Risk)" ขึ้นเว็บไซต์โรงพยาบาล

**สำหรับ: แอดมินเว็บไซต์ (ระบบ B+ CMS ของ BDMS / WordPress)**
**ปรับปรุง: 5 กันยายน 2569**

## ข้อมูลเครื่องมือ (ค่าที่ต้องใช้)

| รายการ | ค่า |
|---|---|
| ชื่อเครื่องมือ (ไทย) | ประเมินความเสี่ยงโรคหัวใจและหลอดเลือดใน 10 ปี (ไม่ใช้ผลเลือด) |
| **URL เครื่องมือ** (โฮสต์บน Cloudflare) | `https://thaicvriskscore.pages.dev/` |

## ขั้นที่ 1 — เลือก slug (ตัดสินใจให้จบก่อนทำ QR)
- ใช้ **ภาษาอังกฤษ สั้น ๆ** เช่น `thai-cv-risk` หรือ `heartcheck-cv`
- URL หน้าเว็บจะเป็น: `https://www.bangkokhospital.com/th/surat/content/{slug}`
- 🔴 เปลี่ยน slug ทีหลัง = QR ที่พิมพ์แจกไปแล้วพังทันที

## ขั้นที่ 2 — สร้างหน้าเว็บ + กรอกข้อมูล (เลือกแท็บภาษาไทย)

| ช่อง | ค่าที่กรอก |
|---|---|
| **Title** | ประเมินความเสี่ยงโรคหัวใจและหลอดเลือดใน 10 ปี |
| **Excerpt** (ห้ามเว้นว่าง) | แบบประเมินความเสี่ยงโรคหัวใจและหลอดเลือดใน 10 ปี สำหรับคนไทยอายุ 35–70 ปี โดยไม่ต้องเจาะเลือด ใช้ข้อมูลพื้นฐาน เช่น อายุ ความดัน รอบเอว รู้ผลทันที (เป็นการคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัย) |
| **Slug** | (จากขั้นที่ 1) |
| **SEO → Meta Description** | ใส่ข้อความเดียวกับ Excerpt |

> ⚠️ **ต้องกรอก Excerpt เสมอ** — ถ้าเว้นว่าง เวลาแชร์ลิงก์เข้า LINE/Facebook จะไปดึงโค้ด JavaScript มาแสดงแทนคำอธิบาย (เคยเกิดจริงกับโครงการวัคซีน)

## ขั้นที่ 3 — วางโค้ดในช่อง Content

**ลำดับที่ห้ามสลับ:**
1. ที่กล่อง Content มุมขวาบน มีแท็บ **Visual** และ **Text** → กด **Text**
2. วางโค้ดด้านล่างทั้งก้อน (ย่อหน้าคำอธิบาย + iframe + script)
3. กด **Publish / Update ทันที**

> 🔴 **ห้ามสลับกลับไปแท็บ Visual ก่อนกด Publish เด็ดขาด** — ตัวแก้ไข (TinyMCE) จะลบ `<script>` ทิ้งเงียบ ๆ ไม่มีแจ้งเตือน ผลคือกรอบสูงค้างและมีแถบเลื่อนซ้อนข้างใน

### 📋 โค้ดที่ต้องวาง (คัดลอกทั้งหมด)

```html
<h2 style="text-align:center">ประเมินความเสี่ยงโรคหัวใจและหลอดเลือดใน 10 ปี</h2>
<p style="text-align:center">รู้ความเสี่ยงหัวใจของคุณ โดยไม่ต้องรอผลเลือด ใช้เวลาประมาณ 1–2 นาที</p>
<p style="text-align:center">สำหรับผู้ที่ยังไม่เคยได้รับการวินิจฉัยโรคหัวใจและหลอดเลือด อายุ 35–70 ปี</p>

<div style="max-width:820px;margin:0 auto;">
  <iframe id="bsrThaiCV"
          src="https://thaicvriskscore.pages.dev/"
          style="width:100%;border:none;height:1800px;display:block;"
          scrolling="no"
          title="ประเมินความเสี่ยงโรคหัวใจและหลอดเลือดใน 10 ปี (ไม่ใช้ผลเลือด)"></iframe>
</div>
<script>
window.addEventListener('message', function(e){
  if (e.data && e.data.type === 'bsr-thaicv-height') {
    var f = document.getElementById('bsrThaiCV');
    if (f) f.style.height = (e.data.height + 20) + 'px';
  }
});
</script>
```

> ในโค้ดนี้กรอกค่าให้ครบแล้ว ไม่ต้องแก้อะไร (URL, message type, title ตรงกับเครื่องมือแล้ว)

## ขั้นที่ 4 — ตรวจหลังเผยแพร่ (เปิด **หน้าเว็บจริง** ไม่ใช่หน้าแก้ไข)

| # | ต้องเห็น | ถ้าไม่เป็นแบบนี้ |
|---|---|---|
| 1 | เครื่องมือแสดงครบ ใช้งานได้ | ดูขั้นที่ 5 |
| 2 | กรอบพอดีเนื้อหา **ไม่มีแถบเลื่อนซ้อนข้างใน** | `<script>` ถูกลบ → วางใหม่โหมด Text แล้ว Publish ทันที |
| 3 | เลื่อนไปหน้าถัดไปของเครื่องมือ กรอบปรับความสูงตาม | เหมือนข้อ 2 |
| 4 | เปิดมือถือแล้วอ่านง่าย ปุ่มกดสะดวก | แจ้งผู้พัฒนา |
| 5 | ชื่อแท็บเบราว์เซอร์เป็นภาษาไทย | ยังไม่ได้กรอก Title |
| 6 | คำอธิบายหน้าเว็บไม่ใช่โค้ด JavaScript | ยังไม่ได้กรอก Excerpt (ขั้นที่ 2) |

> หมายเหตุ: ในหน้าแก้ไขของ CMS อาจขึ้นว่า "script ไม่ทำงาน" เป็นเรื่อง **ปกติ** เพราะโหมด Visual ไม่รัน script — ให้ดูผลจาก **หน้าเว็บจริง** เท่านั้น

## ขั้นที่ 5 — ถ้ากรอบว่างเปล่า ไม่มีอะไรขึ้น (อาจถูก CSP บล็อก)
เว็บโรงพยาบาลอาจตั้งค่าความปลอดภัย (CSP) บล็อก iframe จากภายนอก
→ แจ้ง **ทีมส่วนกลาง BDMS** ให้เพิ่ม `thaicvriskscore.pages.dev` เข้า **frame-src** ของเว็บ

## ขั้นที่ 6 — ล้างแคชก่อนประชาสัมพันธ์
- **CMS (BDMS):** แก้แล้วรอ ~15 นาที
- **Facebook:** `developers.facebook.com/tools/debug` → วาง URL → **Scrape Again**
- **LINE:** 🔴 ไม่มีเครื่องมือล้างแคช ต้องรอ 1–3 วัน → **ต้องแก้หน้าให้จบก่อนเริ่มประชาสัมพันธ์ทาง LINE**

## ขั้นที่ 7 — ทำ QR Code (ทำเป็นขั้นสุดท้าย หลังตรวจผ่าน)
- ชี้ที่ **URL หน้าโรงพยาบาล** เท่านั้น (`bangkokhospital.com/th/surat/content/{slug}`) — **ห้าม**ชี้ `pages.dev` ตรง ๆ
- ใช้ **QR แบบ Static** (ห้ามใช้ QR ฟรีแบบ Dynamic/ย่อลิงก์ เพราะถ้าบริการปิด QR จะตาย)
- ทดสอบสแกนด้วย iPhone และ Android ก่อนพิมพ์จริง
