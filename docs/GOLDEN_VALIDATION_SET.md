# Golden Validation Set — Thai CV Risk Score (Non-Lab)

**Deliverable D.** Confirms the independent engine (`src/calculator/thaiCvNonLab.js`)
reproduces the official Rama-Mahidol Thai CV Risk Score **v2.5 (2021)** reference
implementation across a spread of synthetic cases.

## Method
- **Reference / expected values** were generated by executing the *exact* mathematics
  of the official reference implementation (`docs/reference-formular.js` → `TASCVDformular`)
  on each case, with `WHR = waist_cm / height_cm`. The generator is archived and the
  expected values live in `src/calculator/validationCases.js` (do not hand-edit).
- **Calculated values** come from the production engine, invoked via the model registry.
- **Tolerance:** absolute error on the risk *fraction* `≤ 1e-6` (the reference calculator
  itself displays only 2 decimals of percent, so 1e-6 confirms essentially exact reproduction).
- **Runner:** `node tests/run-all.js` (suite `validation`).

## Result
- **Cases:** 44 (≥ the 20–50 required)
- **Coverage:** male & female; ages 35/40/45/48/50/52/55/58/60/62/65/68/70;
  smoker & non-smoker; diabetic & non-diabetic; SBP 110–190; waist 60–120 cm;
  WHR 0.35–0.75; predicted risk spanning low, moderate, high and very-high bands
  (20 low / 6 moderate / 5 high / 13 very-high), plus the two reference "comparison persons".
- **Outcome:** **ALL 44 CASES PASS.** Maximum absolute error = **4.9 × 10⁻⁷**.
